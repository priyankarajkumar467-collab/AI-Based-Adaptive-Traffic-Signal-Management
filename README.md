# AI-Based Adaptive Traffic Signal Management

## AI-Powered Traffic Optimization for Busy Intersections

**Project Location:** Oppanakara Street, Coimbatore

## Project Overview

Traffic congestion at busy intersections can lead to long waiting times, vehicle queues, unnecessary idling, and inefficient use of traffic signal green time.

This project proposes an AI-based adaptive traffic signal management system that responds to changing traffic conditions instead of relying only on fixed signal timings.

The system observes traffic conditions, detects and classifies vehicles, estimates traffic density and lane-wise demand, and dynamically adjusts signal timing according to current traffic conditions.

## Objectives

- Monitor traffic conditions at Oppanakara Street.
- Detect and classify different vehicle types.
- Estimate traffic density and queue length.
- Analyze lane-wise traffic demand.
- Dynamically adjust traffic signal timing.
- Reduce unnecessary waiting.
- Improve traffic flow.
- Maintain safety while optimizing signal timing.

## Proposed Solution

The system follows this pipeline:

Traffic Observation → Vehicle Detection → Vehicle Classification → Traffic Analysis → Adaptive Signal Decision → Optimized Traffic Flow
